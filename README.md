\# Cyber Echo Tale (Neon Protocol)



A dark, cyberpunk-inspired, choice-based interactive adventure game that runs in the browser.

The game is in Turkish.



\*\*Play it live:\*\* https://hilakkk0.github.io/cyber-echo-tale/



\## Tech stack



\- TypeScript and React

\- TanStack Start (routing and app framework), built with Vite

\- Tailwind CSS and shadcn/ui components

\- Bun as package manager and runtime

\- Deployed to GitHub Pages with GitHub Actions



\## Run locally



```bash

bun install

bun run dev

```



Then open the local address printed in the terminal.



\## Project structure



\- `src/`: application code (routes, components, game logic)

\- `.github/workflows/`: automatic build and deployment to GitHub Pages

\- `components.json`: shadcn/ui configuration



\## Notes



This project started from a Lovable template and was then extended and deployed with GitHub Pages.
